# poe2-build-repo

流亡黯道 2（Path of Exile 2）构筑的简体中文专属攻略页仓库。

每个构筑一个目录，命名为 `<补丁号>-<升华职业中文名>`，例如 `0.5.5-武学家`。
目录内每个变体一个 HTML 文件，文件名为变体的中文名；`_source.json` 保存从原站抓取的结构化原始数据，供下次增量更新比对。

## 生成方式

由 Claude 技能 `poe2-build-cn` 生成，源文件保存在 `skills/poe2-build-cn/SKILL.md`。
输入是一个 mobalytics.gg 构筑链接，中英对照基于 poe2db.tw 的 `/cn/` 与 `/us/` 同页对位。

## 约定

- 词缀中文一律取 poe2db `/cn/`，它与简中客户端一致（已用实物物品名反向验证）。不使用繁中台服口径的数据源。
- 天赋树完整点法不在本仓库内，读者对着原站点；页面只标核心节点。
- 每页末尾的「数据核验」一节记录哪些数值经过查证、哪些是暂译、原站自相矛盾之处。

## Windows 下的 git 配置

仓库使用中文目录与文件名，克隆后先执行：

```
git config core.quotepath false
```
